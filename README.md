🎲 Dice Roller

A simple and fun Dice Roller Web App built using HTML, CSS, and JavaScript.
Click the ROLL button to simulate rolling a dice — complete with sound and animation!

##Features

Generates a random dice number between 1 and 6.

Plays a dice-rolling sound effect for a realistic feel.

Displays a spinning animation effect before showing the final result.

Simple, clean, and beginner-friendly code structure.

## Technologies Used

HTML5 – for structure

CSS3 – for styling

JavaScript (ES6) – for logic and interactivity

##Project Structure

dice-roller/
│
├── index.html      # Main HTML file
├── style.css       # Optional styling (can add dice graphics or layout)
├── random.js       # JavaScript logic for dice roll
└── dice-142528.mp3 # Dice rolling sound effect

How It Works

When you click ROLL, the app:

Plays the dice sound.

Shows rapidly changing random numbers (like spinning).

Stops after a short duration and displays the final dice number (1–6).

The animation simulates a real dice roll experience!
